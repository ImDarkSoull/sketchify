# Sketchify example

A showcase app for [sketchify](https://pub.dev/packages/sketchify). Pick a sample (or your own image) and watch it draw itself in. Then try the style presets, playback controls and timeline scrubber.

```bash
cd example
flutter run
```

It runs on Android, iOS, web, macOS, Windows and Linux. The "Your image" button uses [`file_selector`](https://pub.dev/packages/file_selector).
